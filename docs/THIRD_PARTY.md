# Third-party components

Apache-2.0 covers the project's first-party contributions, subject to the contributor's rights. Dependencies, fonts, documents and other third-party material retain their respective licences. This file is not a completed legal clearance or a replacement for required attribution.

Before distributing a release, inventory the exact package-lock.json dependency tree, including transitive dependencies and bundled assets. Record package name/version, source, SPDX expression and required copyright/licence/NOTICE text. Check the actual shipped distribution, not just package metadata.

The SMTP package named smtp-mailer is an npm alias for Nodemailer. Review its underlying package licence. Verify rights and provenance for the legal control libraries in data/ before publication. Preserve any third-party notices; do not relabel third-party work as first-party code.

This repository does not yet include a verified complete third-party notice bundle. Complete that review before a commercial distribution.
